# StackMachine SDKs

Client SDKs for StackMachine.

## JavaScript and TypeScript

```bash
npm install stackmachine
```

See the [JavaScript SDK README](./js/README.md).

## Python

```bash
uv add stackmachine
```

See the [Python SDK README](./python/README.md).

## Rust

An async Rust SDK is available as the `stackmachine` crate in `rust/`.

```toml
[dependencies]
stackmachine = { path = "path/to/sdks/rust" }
```

See the [Rust SDK README](./rust/README.md).
